# Правила разработки МедТехСервиса

- Работай строго в этом репозитории и выполняй одну поставленную задачу за раз.
- Не добавляй секреты, токены, пароли, реальные клиентские данные или содержимое `.env`.
- Не выполняй production-действия и не обращайся к реальным Telegram, SMTP, IMAP, 1С, Dokploy или другим внешним провайдерам.
- Клиент ходит только в Supabase (Auth, PostgREST, Storage). Внешние системы не вызывай из браузера.
- Не запускай Docker на общей рабочей ВМ. Конфигурацию Supabase можно изменять статически.
- Пользовательский интерфейс и документацию продукта пиши на русском языке, если задача не требует другого.
- Не выполняй git commit, push, pull request, merge или deploy, пока это явно не запрошено.
- Сохраняй границы задачи и существующее поведение вне её scope.
